# Who are you rooting for?

ROOTR lets anyone launch a coin for anyone. Paste a handle. A coin exists, with liquidity that can never be pulled. People root for the person by trading it. The person earns from every trade and can claim what is theirs by proving the handle. And unlike every person coin before it, the people doing the rooting earn too.

Every ROOTR feeds the next ROOTR.
